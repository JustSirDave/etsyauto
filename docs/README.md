## 📝 Documentation Conventions

### Symbols Used

- ✅ = Complete/Working
- ⏳ = In Progress/Waiting
- ❌ = Failed/Error
- 🔧 = Configuration Required
- 💡 = Tip/Helpful Info
- ⚠️ = Warning/Important
- 🚀 = Quick Start
- 📊 = Statistics/Data

### Code Blocks

**Bash Commands:**
```bash
docker compose up -d
```

**Configuration:**
```env
ETSY_CLIENT_ID=your_key
```

**API Requests:**
```bash
curl -X POST http://localhost:8080/api/...
```

### Formatting

- **Bold**: Important terms, actions
- *Italic*: Emphasis, variables
- `Code`: Commands, file names
- > Quote: Notes, warnings
